# Troubleshooting

Every error response has `error.code`, a safe `message` and a `requestId`. Search the Lambda logs for the `requestId`: `request failed` entries include the Graph status, Graph error codes and the Graph `request-id`.

| Symptom                                                          | Likely cause                                                                                                                       | Fix                                                                                                                    |
| ---------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| 401 from API Gateway, nothing in the Lambda logs                 | Token rejected by the JWT authorizer: wrong audience (e.g. a Graph or ID token), wrong issuer (v1 token), missing `access_as_user` | The SPA must request `api://<api-client-id>/access_as_user`. Set `requestedAccessTokenVersion: 2` in the API manifest. |
| 401 `UNAUTHENTICATED` "Tokens from this tenant are not accepted" | Signed in with another tenant's account                                                                                            | Use a user from the configured tenant                                                                                  |
| 403 "Application tokens are not accepted"                        | Client-credentials (app-only) token                                                                                                | McSheety routes need a signed-in user                                                                                  |
| 401 with `claimsChallenge`                                       | Conditional Access requires MFA or a compliant device                                                                              | The client retries automatically with the claims; the redirect flow re-prompts                                         |
| 403 with detail `consent_required`                               | Admin consent missing for the API's Graph permissions                                                                              | Grant admin consent on the API registration                                                                            |
| 403 "does not have access to this workbook"                      | SharePoint denies this user (Graph 403)                                                                                            | Grant the user access to the file or site                                                                              |
| 403 `FORBIDDEN` for an action                                    | McSheety policy: no role grants it, the field isn't writable, or the row is outside scope                                          | Check app role assignment, `mc_permissions`, `mc_columns`, `mc_rowPolicies`                                            |
| Editor sees zero rows                                            | Row policy needs `departmentId`, and the user has none (fails closed)                                                              | Set the user's Department in Entra and configure `MCSHEETY_ATTRIBUTES` (notes.md §1e)                                  |
| 404 for a table that exists                                      | No role grants anything on it, **or** its metadata has errors and it is disabled                                                   | Run `mcsheety validate` on a downloaded copy; check `workbook metadata errors` in the logs                             |
| 409 `CONFLICT`                                                   | Stale `If-Match`, the row changed in Excel since it was read, or a duplicate id/unique value                                       | Re-read and retry; fix duplicate IDs in the sheet                                                                      |
| 428 `PRECONDITION_REQUIRED`                                      | PATCH/DELETE without `If-Match`                                                                                                    | Send the record's `revision`                                                                                           |
| 429 `RATE_LIMITED`                                               | Graph or API Gateway throttling                                                                                                    | Honour `Retry-After` (the client does for reads)                                                                       |
| 503 `WORKBOOK_UNAVAILABLE`                                       | Workbook locked, session expired, Graph outage, table above `MCSHEETY_MAX_ROWS`, or wrong drive/item ID (404)                      | Retry; check the drive/item IDs; split large tables                                                                    |
| Lambda init error "Invalid McSheety configuration: …"            | Missing or invalid `MCSHEETY_*` variables                                                                                          | The message lists every problem                                                                                        |
| `cdk synth` fails with `spawnSync pnpm ENOENT`                   | CDK bundling needs pnpm on PATH                                                                                                    | `corepack enable`                                                                                                      |
| Values in Excel show a leading `'`, or dates became numbers      | Graph text-encoding behaviour differs from ADR 0002 assumption A3                                                                  | Report the probe output; switch to number-format encoding                                                              |
